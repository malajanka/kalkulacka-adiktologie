# Kalkulačka financování adiktologických služeb

Interaktivní kalkulačka k dotačnímu programu Protidrogová politika v návrhu státního rozpočtu 2027. Postavená v [marimo](https://marimo.io); Python běží přímo v prohlížeči (WebAssembly), bez serveru.

- `kalkulacka_adiktologie.py` – zdrojový notebook (`marimo edit kalkulacka_adiktologie.py`)
- ostatní soubory – export `marimo export html-wasm kalkulacka_adiktologie.py -o . --mode run`

Zdroje dat jsou uvedené přímo v kalkulačce (sekce „Zdroje a metodika“).
