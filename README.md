# Kalkulačka: program Z3531 (protidrogová politika) v návrhu SR 2027

Interaktivní kalkulačka v [marimo](https://marimo.io). Python běží přímo v prohlížeči (WebAssembly), bez serveru.

- `z3531_kalkulacka.py` – zdrojový notebook (`marimo edit z3531_kalkulacka.py`)
- ostatní soubory – export `marimo export html-wasm z3531_kalkulacka.py -o . --mode run`

Zdroje dat jsou uvedené přímo v kalkulačce (sekce „Zdroje a metodika“).
